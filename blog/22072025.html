Nmap : Guide pratique du scan réseau

Nmap (Network Mapper) est un outil indispensable en cybersécurité pour l’exploration réseau, la détection d’hôtes et de services, l’analyse des règles de pare-feu et la détection de vulnérabilités. Ce guide vous présente les commandes essentielles pour bien démarrer, avec des explications concrètes et des exemples pratiques.

Partie 1 – Découverte du réseau

1.1 – Identifier sa propre machine et le réseau

Avant de scanner un réseau, identifiez votre IP et votre plage réseau :

ifconfig ou ip a

Vous obtiendrez une IP comme 192.168.100.X, ce qui suggère une plage 192.168.100.0/24.

1.2 – Découverte des hôtes actifs

Nmap permet de découvrir les machines connectées via un ping sweep :

nmap -sn 192.168.100.0/24

-sn désactive le scan de ports, utile pour une simple détection des hôtes.

Autres techniques :

  • nmap - Découverte via SYN sur les ports 80 et 443
    nmap -sn -PS80,443 192.168.100.0/24

  • nmap - Découverte via UDP vers le port 53
    nmap -sn -PU53 192.168.100.0/24

  • nmap - Découverte ARP (réseau local)
    nmap -sn -PR 192.168.100.0/24

La méthode ARP est la plus fiable en LAN car elle ne peut pas être bloquée.

Partie 2 – Identification des ports, services et OS

2.1 – Scan de ports

Un scan des 1000 ports TCP les plus courants :

nmap 192.168.100.X

Sans -sV ni -A, vous ne verrez que les ports ouverts, pas les versions ni les services.

2.2 – Détection du système d’exploitation et version des services

  • nmap - Détection de l'OS
    nmap -O 192.168.100.X

  • nmap - Scan agressif (OS, services, scripts de base)
    nmap -A 192.168.100.X

  • nmap - Script NSE : banner, version, découverte SMB
    sudo nmap --script=banner,version 192.168.100.X
    sudo nmap --script=smb-os-discovery 192.168.100.X

Nmap se base sur le TTL, les signatures TCP/IP, les bannières et sa base nmap-os-db.

Partie 3 – Analyse des pare-feu

3.1 – Ports filtrés ou fermés ?

  • nmap - Scan furtif SYN sur des ports spécifiques
    nmap -sS -p 21,22,80 192.168.100.X

  • nmap - Scan ACK pour identifier les ports filtrés
    nmap -sA -p 21,22,80 192.168.100.X

Port fermé : réponse RST
Port filtré : aucune réponse ⇒ possible filtrage pare-feu

3.2 – Contournement de pare-feu

  • nmap - Scan fragmenté
    sudo nmap -sS -f -p 80,443 192.168.100.X

  • nmap - Utiliser un port source spécifique (ex: DNS)
    sudo nmap -sS --source-port 53 -p 21,22 192.168.100.X

  • nmap - Scan lent et discret
    sudo nmap -sS -T1 -p 21,22,80,443 192.168.100.X

Combinez ces options pour tester des IDS/IPS ou firewalls plus robustes.

Partie 4 – Scanning avancé avec NSE

4.1 – Scripts NSE par catégories

  • nmap - Script de découverte réseau
    sudo nmap --script=discovery 192.168.100.X

  • nmap - Script lié à l'authentification
    sudo nmap --script=auth 192.168.100.X

  • nmap - Script de détection de vulnérabilités
    sudo nmap --script=vuln 192.168.100.X

4.2 – Scans ciblés et complets

  • nmap - Scan complet tous ports TCP
    sudo nmap -p- -A -T4 192.168.100.X

  • nmap - Extraire uniquement les ports ouverts
    sudo nmap -p- --open 192.168.100.X -oG - | grep "/open/" ...

  • nmap - Scan UDP des ports les plus courants
    sudo nmap -sU --top-ports=20 192.168.100.X

Partie 5 – Furtivité et reporting

5.1 – Éviter la détection

  • nmap - Scan très lent et discret
    sudo nmap -sS -T0 --max-parallelism 1 --max-retries 0 192.168.100.X

  • nmap - Utilisation de leurres (decoys)
    sudo nmap -sS -D 192.168.100.200,192.168.100.201,ME 192.168.100.X

  • nmap - Hôtes aléatoires avec délai entre chaque
    sudo nmap -sS --randomize-hosts --scan-delay 5s 192.168.100.0/24

5.2 – Générer un rapport

  • nmap - Export en XML
    sudo nmap -A 192.168.100.0/24 -oX scan_results.xml

  • xsltproc - Conversion des résultats Nmap en HTML
    xsltproc scan_results.xml -o scan_report.html

  • nmap - Sortie multi-formats (nmap, XML, gnmap)
    sudo nmap -A 192.168.100.0/24 -oA full_scan

Conclusion

Nmap est un couteau suisse pour tout analyste sécurité, pentester ou admin réseau. Bien utilisé, il offre une vision complète d’un environnement réseau, tout en fournissant les outils pour contourner les protections et automatiser l’analyse.

Attention : à utiliser uniquement dans un cadre légal, sur des systèmes que vous avez le droit de scanner.
