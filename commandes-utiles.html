Commandes utiles (experimental)

Ici, je regrouperai toutes les commandes que je choppe au passage et qui pourraient être utiles plus tard.

  • keyboard - Configurer la langue du clavier
    dpkg-reconfigure keyboard-configuration

  • ssh - Se connecter en ssh sur un hôte
    ssh <user>@<addr_ip>

  • ip - Lister les interfaces réseau
    ip a

  • nmap - Scan simple d'un hôte pour identifier les ports ouverts
    nmap <addr_ip>

  • nmap - Scan d'un hôte pour identifier les versions des services actifs sur les ports ouverts
    nmap -sV <addr_ip>

  • nmap - Scan d'un hôte en profondeur (OS et service)
    nmap -A <addr_ip>

  • nmap - Scan d'un hôte sur les ports spécifiés
    nmap -p <port,port,port> <addr_ip>

  • nmap - Scan furtif d'un hôte (SYN scan)
    nmap -sS <addr_ip>
