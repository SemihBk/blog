Commandes utiles (experimental)

Ici, je regrouperai toutes les commandes que je choppe au passage et qui pourraient être utiles plus tard.

  • install - Installer un paquet
    apt install <package>

  • update - Télécharger la liste des paquets disponibles
    apt update

  • upgrade - Installer la liste des mises à jour des paquets disponibles
    apt upgrade

  • keyboard - Configurer la langue du clavier
    dpkg-reconfigure keyboard-configuration

  • user - Créer un nouvel utilisateur
    adduser <username>

  • ssh - Se connecter en ssh sur un hôte
    ssh <user>@<addr_ip>

  • ip - Lister les interfaces réseau et leurs configurations
    ip a

  • ip - Afficher les informations réseau de l'interface réseau
    ifconfig

  • nmap - Scan simple d'un hôte pour identifier les ports ouverts
    nmap <addr_ip>

  • nmap - Scan d'un hôte pour identifier les versions des services actifs sur les ports ouverts
    nmap -sV <addr_ip>

  • nmap - Scan d'un hôte en profondeur (OS et service)
    nmap -A <addr_ip>

  • nmap - Scan d'un hôte sur les ports spécifiés
    nmap -p <port,port,port> <addr_ip>

  • nmap - Scan furtif d'un hôte (SYN scan)
    nmap -sS <addr_ip>

  • processus - Lister la liste des processus en cours
    ps aux

  • processus - Tuer un processus avec son PID
    kill <PID>

  • ping - Tester la connectivité avec un hôte
    ping <addr_ip>
